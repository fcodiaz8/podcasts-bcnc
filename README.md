# Variables de entorno

Antes de ejecutar la app, puede crear un archivo `.env` en la raíz del proyecto
basado en el archivo `.env.example`, y ajustar las variables de entorno según sea necesario.

Cuando sea posible y seguro, las variables contarán con valores por defecto (consulte el archivo `.env.example`).
